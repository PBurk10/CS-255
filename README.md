For this class I had to implement a system for my client DriverPass. The system is designed to assist students who are training to take their driver test. This system is a web-based app that allows students to select a driving package and work directly with instructors. This system also allows students to take practice tests online and study the latest DMV regulations. Students will be able to schedule driving lessons either on the app or call the DriverPass secretary to schedule. 
I believe that I did a good job at listing the different technical requirements for this project as I highlighted all the different requirements needed to make this system succeed.
One area that I would have liked to highlight more would be for security of the system. I didn't mention enough about how important it is to protect the system from malicious attacks. This would have helped get a clearer picture of how the system will protect its users' personal information.
Reading the DriverPass interview was crucial to designing the system. I kept reading what functions that DriverPass wanted in place and always had them in mind when coming up with a design. It is extremely important to always listen to the client's needs when designing a system because the system is meant for them.
Clear communication throughout the development life cycle is the most important step because if the communication breaks down, then the system won't be designed in the way that the client desires.
